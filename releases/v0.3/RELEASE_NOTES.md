# SpongeBob Movie Debug Tools v0.3

**Status: stable release.** Target USA PS2 `SLUS_209.04`. The distributable ZIP SHA-256 is recorded on the GitHub release page and in RELEASE_READINESS.md. This version promotes the existing HealthMenu patch to the owner-tested PS3/ps2_netemu baseline; **no newly recovered retail developer menu is claimed**.

## Included

Seven cumulative patch stages: controller-debug overlay, Select hide/show, interactive debug panel, music pause/resume, XYZ and scene/controller diagnostics, reversible Damage 0/1, and read-only live HP beside Damage. Each patcher requires the SHA-256 of its own *immediately preceding stage* and makes a separate ISO. For a user with DamageMenu already generated, the HealthMenu patcher needs the **DamageMenu** image, *not* the original retail ISO. See [tools/README.md](../../tools/README.md) and [stage manifest](../../tools/STAGES.json).

## What has been tested

- **PS3 owner report:** HP3 to HP1 after two enemy hits; recovered HP2; Damage 0 blocks ordinary hit damage and Damage 1 restores it; stable restart with HP3; level 1 to 2 with HP3; Select hide/show; owner reported other options continue to work. Observed coverage is described in [console-validation notes](../../docs/HEALTH-MENU-CONSOLE-VALIDATION-2026-10-22.md). No independently captured trace; console-side identity previously checked by Muse.
- **Neptune / Muse report:** 14/14 patcher fixtures passed with wide terminal buffer; seven ISO stages regenerated byte-identically and source ISOs remained unchanged. The test harness can false-fail the “existing output” fixture if PowerShell wraps text at 80 columns. This should be fixed, but is not evidence of a corrupted patch.
- **HealthMenu expected SHA-256:** `fbfa8154a436e7c1cb1a06b54b85296524ab151d1098bcf631b0b8e3ec9e629a`. **DamageMenu input SHA-256:** `9df1860529ac4e6e5d2bb542ba59b1c171bb1ae797a24c8aef80eb75c4a12630`.

## Limitations

- Tested through PS3 Slim CFW PS2 software emulation. Original PS2, PCSX2, other emulator families and extended game modes **not yet verified**.
- Original developer/debug menu restoration **not confirmed**; all menu rows are custom.
- `G.CheatFlyToggle`, `DebugMode`, and `E3DemoStart` remain investigation targets; not shipped as working controls. No Free Camera or level selection.
- No proprietary game ISO, executable, or assets may be packaged or uploaded.

## Release gate (satisfied for v0.3)

The distributable ZIP was built from the committed repository (see SOURCE_COMMIT.txt inside the ZIP), the fixture and full-image stage tests were run against that exact packaged distribution on Neptune (14/14 fixtures, 7/7 stages, sources unchanged), the ZIP contents were audited to exclude game data, and the ZIP SHA-256 was recorded on the GitHub release page. The packaged run receipt is releases/v0.3/VERIFICATION.json.
