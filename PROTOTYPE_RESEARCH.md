# Movie prototype research

Updated October 21, 2026. Prototype search now includes any platform, as requested. PS2 remains the target for cheat/debug restoration. Free camera and level selection remain outside the requested feature scope.

## Archived debug-disc lead

[Large Nintendo Development sale (UK), ASSEMblergames archive](https://assemblergames-archive.com/thread-16132.html), posted March 18, 2008 by Parris:

The seller lists an NTSC GameCube NR disc for the Movie, labeled THQ Debug, dated 2004, attributed to Heavy Iron Studios. The listing marks it taken in trade by forum user Kiff.

This is historical seller testimony, not an inspected build. No exact build date, hash, public dump, or debug-menu behavior has been verified. It must not be assumed to be the same as the later French/Dutch localization dump.

Thread pages 2–4 were also retrieved; no public dump has been established from this investigation.

## PS2 lead

The August 31, 2004 PS2 test disc remains documented in [Heritage Auctions lot 79058](https://comics.ha.com/itm/video-games/other/the-spongebob-squarepants-movie-game-wata-certified-prototype-test-build-8-31-2004-the-harvey-collection-ps2-thq-2004-usa/a/44210-79058.s). A public dump is still unverified.

## Priority

1. Inspect the English GameCube compilation candidate for executable differences and surviving debug functionality.
2. Trace public documentation or a release of the NTSC THQ Debug NR disc.
3. Keep pursuing the PS2 August 31 test build.
4. Use GBA only as a separate prototype investigation.

Cross-platform findings are research leads. Addresses, binaries, and patch instructions require validation against the actual target build.
