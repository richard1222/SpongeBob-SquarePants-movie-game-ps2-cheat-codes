# v0.4 symbol-to-PS2-function matching — 2026-10-22

Purpose: correlate named GameCube Movie decompilation functions and Muse's independently recorded PS2 retail ELF observations **without copying GameCube addresses**. This is a static-analysis plan and evidence inventory, not a new ISO patch or PS3 runtime result.

## Directly inspected upstream references

- [TSSM zGameExtras.h](https://github.com/bfbbdecomp/tssm/blob/main/src/SB/Game/zGameExtras.h) declares `GECheat` as key-code pointer, cheat callback, keep flag and mode flag; names `TestCheat`, `AddToCheatPressed`, `GEC_CheatFlagAdd`, `GEC_CheatFlagToggle`, `zGameExtras_CheatFlags`, scene save/load/reset and many `GEC_cb_*` callbacks.
- [TSSM zGameExtras.cpp](https://github.com/bfbbdecomp/tssm/blob/main/src/SB/Game/zGameExtras.cpp) contains partial reconstructed implementation: `zGameExtras_Load` merges saved cheat flags, `zGameExtras_Save` writes low 16 bits, `zGameExtras_CheatFlags` exposes the flag word; extras checks include calendar-dependent flags. **This is GameCube work-in-progress code and not proof of identical retail PS2 implementation.**
- [TSSM xDebug.h](https://github.com/bfbbdecomp/tssm/blob/main/src/SB/Core/x/xDebug.h) declares `xDebugModeAdd`, `xDebugInit`, `xDebugUpdate`, `xDebugAddTweak`, `xDebugRemoveTweak`, and rich `tweak_info` callbacks/types. The declarations demonstrate planned APIs, **not** working original PS2 debug UI.
- [TSSM DWARF xDebug](https://github.com/bfbbdecomp/tssm/blob/main/dwarf/SB04_Multi_Sku/Engine/Core/x/xDebug.cpp) represents a symbol-bearing **different layout**; Muse reports a largely stubbed debug subsystem there.

## Muse's PS2 evidence available now

Muse's [retail executable sweep](XBOX-DEMO-BINARY-STATUS-AND-DEV-SWEEP-2026-10-22.md) records PS2 `SLUS_209.04` ELF SHA-256 `2ff117f45e80be5e2d73b6c952f4b5adfb8d359c8cc6c14eb5906197994ce956`. It confirms:
- `0x00403B70–0x00403BAC`: return-only stub slots; `0x00403BB0`: surviving active controller-debug update entry. Existing custom menu uses this route.
- INI `displayPadDebugInfo` parsed and retained handler called. Debug-related strings include `Demo running in debugger -- overriding bogus params!` and `No HIS debugging`.
- Retail MN archives contain cheat-entry sound/group identifiers including `CHEAT_SUCCESS`, `CHEAT_STEP_GRP`, `CHEAT_FAILED_GRP` and `menu_cheat_*.WAV`; retail `SB04.INI` includes Function/Cheat extras descriptions.
- No PS2 ELF DWARF/symbol table. None of these statements locates PS2 `TestCheat` or a specific callback yet.

## Required evidence format

For each proposed match, capture: upstream function and commit; PS2 executable SHA-256; PS2 function start/end; original MIPS words; caller addresses; anchor strings/global reads/writes; why alternatives were rejected; **confidence** (confirmed instruction/call graph, inferred, or unknown). Provide a disassembly snippet/behavioral trace, not just a matching name.
