# Health-refill review and test-harness correction

- Date: October 22, 2026.
- Target: USA PS2 SLUS_209.04, current v0.4 development source.
- Goal: check the imported health-refill candidate independently and fix the reported wrapped-error false failure.
- Success condition: preserve the candidate's pinned bytes, execute its callback paths against retail, and keep error-message checks valid across whitespace wrapping.

## Rundown

**Proven locally:** eight message-matching tests, all 14 patcher fixtures, and 352 retail-versus-patched callback comparisons pass. The candidate ISO's executable matches the tested patch exactly. No game patch bytes or stable release assets changed.

The review corrects errors in the earlier callback description: the tail hashes `PAUSESTATE MENU OR POWERUP COUNTER` at **0x0061FEC4**, not the nearby ` 10 HP UIF CONFIRM` string at 0x0061FE64. It calls 0x003EB940 only when the lookup returns an object whose state at +0x14 **equals 2**, not when the state differs. The unlockables fallback byte index comes from the entry's +8 word. These are documentation corrections; the existing detour preserves retail behavior at these sites.

**Unknown:** the candidate's console behavior. It remains an isolated clean-retail experiment, not a combined HealthMenu-plus-refill release.

## Harness fix

`tools/test_patchers.py` previously searched raw captured output for phrases such as `already exists`. A line-wrapped `already\nexists` fails that check even when the patcher correctly rejects an existing output. The helper now normalizes whitespace in both expected and captured text before a case-insensitive match. Exit codes, file preservation, expected bytes, hashes and temporary-file checks remain required.

Eight regression tests reproduce the wrapped-text failure, check spaces/tabs/CRLF and casing, and confirm that missing or different errors still fail. The complete 14-fixture PowerShell suite passed after the change. The current default-console run also passed before the change; the reproduced defect is specifically the wrapped-message case, not a newly observed patcher malfunction.

## Callback execution checks

`tools/health-refill-test/test_health_refill.py` executes actual original and manifest-patched R5900 instruction words, including branch/call delay slots and the callback's stack return. It checks the original ELF hash and the patched ELF hash. With `--patched-iso`, it verifies the complete ISO SHA-256 and compares its extracted executable bytes with the simulated image.

The helper still assumes a valid live player, as documented in the original experiment. This review does not add a pointer guard or claim safety in every game state.
