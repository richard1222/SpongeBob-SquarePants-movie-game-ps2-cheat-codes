## Harness fix

`tools/test_patchers.py` previously searched raw captured output for phrases such as `already exists`. A line-wrapped `already\nexists` fails that check even when the patcher correctly rejects an existing output. The helper now normalizes whitespace in both expected and captured text before a case-insensitive match. Exit codes, file preservation, expected bytes, hashes and temporary-file checks remain required.

Eight regression tests reproduce the wrapped-text failure, check spaces/tabs/CRLF and casing, and confirm that missing or different errors still fail. The complete 14-fixture PowerShell suite passed after the change. The current default-console run also passed before the change; the reproduced defect is specifically the wrapped-message case, not a newly observed patcher malfunction.
