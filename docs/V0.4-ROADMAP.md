## Known verified input for the isolated probe

- Start a level, pause with START, hold **L1 + L2 + R1 + R2**.
- **Square** ×6, then **Circle** ×2. **Not Triangle**: the first documentation confused Square with Triangle, leading to a false-negative test and talking-character interaction.
- Probe SHA-256: `f603d78aa4be977bdc06d4ab77da322547c549de764fe580501bd90a2225e4ac`.
- Original USA retail SHA-256: `c0494ad78fab34dc19fb52b831facb1b27500e66bf0a57a77e627e7b805096f0`.
- Existing stable HealthMenu SHA-256: `fbfa8154a436e7c1cb1a06b54b85296524ab151d1098bcf631b0b8e3ec9e629a`.
- Original cheat flag `0x00636FA4` and game state `0x00636FB0` are the **corrected** PS2 addresses; earlier `0x006375A4`/`0x006375B0` labels were wrong.
- Tested sequence-replacement bit `0x10000000` is not written by the original game's `flags & 0xFFFF` save function; this does **not** prove every future cheat callback will be save-safe.

## Parallel research (not release gates)

- **Recoverable developer features:** PS2 cheat flags, Extras, in-game UI paths, debug stubs; retain distinction between *original functions* and our custom menu.
- **Cut content:** GG01 (Goofy Goober Dream) has only configuration residue in retail; no actual level/text archives remain per Muse's file sweep. Requires verified earlier content-bearing build to claim genuine restoration. [GG01 handoff](MUSE-GG01-RETAIL-NEGATIVE-FINDINGS-2026-10-22.md).
- **Prototype hunting:** PS2 August 31 2004 physical prototype has no verified public dump; distinguish U.S. OPM and Asian/European demo-disc numbering, and demand provenance before classifying a beta.
- **Emulator compatibility:** no `SLUS_209.04` per-game CONFIG was found on the owner's PS3; don't introduce CONFIG changes in a game-code-only experiment. [NetEmu research](PS3-SLIM-PS2-NETEMU-TECHNICAL-RESEARCH-2026-10-22.md).
