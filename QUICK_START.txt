SELECT shows/hides; UP/DOWN selects a row; X changes its value.
Rows: Music, XYZ, Scene/controller, Damage with current HP.
Damage 1 is normal damage; Damage 0 disables the tested ordinary-hit path.
Hiding the menu does not reset Damage.

Refill: in a level, START pause, hold L1+L2+R1+R2 and press
CIRCLE x4, SQUARE, CIRCLE, SQUARE, CIRCLE. Release shoulders and resume.
The original cheat grants six slots; refill sets HP to the current maximum.
No new menu row is added. Use a spare save: slot upgrades can persist.

unverified. This is a custom menu, not a restored original developer menu.
